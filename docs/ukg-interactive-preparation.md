# UKG interactive preparation observations

UKG support remains identity-only. An explicitly requested, authenticated
application was filled through the registered Browser Use CLI and preserved as
a guarded review draft. This does not enable scheduled preparation or submission,
and it does not establish a reusable UKG adapter or a verified final-submit path.
No terminal application action was tested.

Each live operation selected the exact existing application tab and held the
shared browser lane. Background rendering and native-input failures were resolved
by activating only that tab after the failure was observed. Other tabs and drafts
were preserved. Required answers, optional blanks, selected documents, saved
repeaters and a fresh full-page screenshot were retained in the private review
packet. Candidate values and account details are not part of this document.

## Observed controls

- Resume upload opens an import-review screen. Parsed work descriptions can absorb
  unrelated resume sections, and parsed skills can acquire unsupported proficiency
  ratings. Check every imported record against the chosen source resume before
  using the nonterminal Save and Continue action. Preserve original summaries and
  reset unsupported ratings to the actual Not Specified catalog option.
- Work and education editors use native controls and month/year dates. Saved
  cards remain visible after the editor closes and must be independently compared
  with the verified source. An expected degree must remain explicitly in progress;
  a future end date alone does not establish that the degree is completed.
- Degree/major catalogs may lack the factual source value. Use an explicitly
  approved catalog fallback only when available, preserve the factual degree in
  its text field, and show the actual catalog selection separately in the review.
- Additional skills accept a native custom-entry path. Include only verified
  chosen-resume skills and relevant coursework; avoid importer fragments or
  proficiency claims inferred from experience duration.
- Link editors rerender when another row is added. Recheck every earlier row
  before saving, then read the saved visible links and exact destinations.
- Start-date controls live in shadow DOM as month/day/year segments. Native
  Backspace can move focus to the preceding segment. Focus and selection must be
  checked per segment; replacing the selected text directly and verifying the
  exact retained ISO date avoids a day or month shifting into another segment.
- Screening questions use native grouped radios; the group question and every
  option must remain distinct from individual Yes/No labels. Selection can reveal
  additional required questions or demographic catalogs, so re-observe after each
  relevant selection.
- The mailing-address Country selector does not constitute a phone-country
  control. Determine phone formatting from the actual phone widget.
- A selected uploaded document has a filename, attachment checkbox and native
  document-type catalog. File inputs may clear after upload; retain the original
  upload byte hash and separately audit the selected visible attachment. An
  arbitrary document slot is not proof that a cover letter is required.
- Optional contact fields, work-style/motivation sections and license sections
  remain visible as blanks in the review inventory. An AI-specific certification
  answer must not imply an answer about every professional license.

## Validation boundaries

Public unauthenticated job-page metadata established the exact job identity,
posting text and open state. Live CLI checks established retained form values,
saved employment/education cards, selected resume, links, native validation state
and terminal guard. Source and document hashes, snapshots and screenshots remain
ignored private evidence. Neither public metadata nor a fixture can substitute
for the final native retained-value audit.

Export-control notices require separate factual screening answers. A general
notice is not itself an explicit citizenship exclusion, and citizenship,
immigration status, unrestricted authorization, current legal work authorization
and sponsorship must not be conflated. Employer eligibility remains a review
consideration even when the application accepts the candidate's truthful answers.

Authentication, expiration recovery, generalized control ownership, independent
terminal review and positive submission receipts still need board-specific
validation before either UKG capability flag can be enabled. The guarded draft
and its complete inventory support human review and manual takeover only.
